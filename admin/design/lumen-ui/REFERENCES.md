# Visual research notes

This kit takes high-level inspiration from [Orvia Mail](https://orviamail.com/) and [Orvia Mail for iPhone](https://orviamail.com/iphone), reviewed on 2026-09-29.

Observed direction:

- Large, tightly tracked editorial headlines with muted continuation text.
- Soft white page backgrounds with restrained light-gray panels and a compact frosted navigation shell.
- Near-black pill actions and small, contextual accent indicators.
- Product storytelling driven by a clear claim, sparse supporting copy and one primary action.
- Mail patterns focused on the immediate action: reply, create an event, add a task or copy a verification code.
- Mobile treatment based on a single, stacked card at a time.

Lumen UI intentionally does not copy protected visual assets, distinctive logos, names, product screenshots, source code or product claims. Its tokens, component markup and examples are newly authored.
